Core Capabilities

🧠

Semantic Sorting

Uses local zero-shot NLP models (Hugging Face) to understand document content and route files to topic-specific folders.

🖼️

Visual Clustering

Identifies visually similar and duplicate images using perceptual hashing, grouping them for easy review without deleting them.

🕰️

Time-Decay Archive

Automatically compresses and archives files that have been untouched for months, saving disk space while maintaining an index.

💻

Project Detection

Finds developer folders (node_modules, .venv) and relocates heavy projects to a dedicated workspace to declutter your Downloads.

Easy Setup

1

Clone & Install

git clone https://github.com/yourusername/shadow-sort
pip install -r requirements.txt
2

Configure

Tweak labels, confidence thresholds, and retention periods in config.yaml.

3

Run Locally

python src/cli.py --path ~/Downloads
